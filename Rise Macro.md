# Rise Macro - Installation & User Guide

Follow the steps below to properly install and configure the macro.

---

## Features

- Slide
- Auto E-Dash
- Auto Jump
- Auto 360

---

## Installation Steps

### Step 1: Install AutoHotkey v2
AutoHotkey v2 must be installed on your system for the script to work.

1. Download the official installer: [AutoHotkey v2 Download](https://www.autohotkey.com/download/ahk-v2.exe)
2. Run the downloaded installer and complete the setup.

---

### Step 2: Download Rise Macro
1. [Click here to download Rise Macro](https://github.com/ShadowBey01/Rise-Macro/releases/tag/Rise)
2. Download the `RiseMacro.rar` file from the latest release.

---

### Step 3: Extract and Run
1. Extract (unrar) `RiseMacro.rar` to any folder on your computer.
2. Open and run `RiseMacroV1.ahk`.
